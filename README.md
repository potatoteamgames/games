🥔 Potato Team Games

Free Games. No Downloads. Just Fun!

Welcome to the official GitHub repository for Potato Team Games, an indie game development team from Denmark.

We create free browser games because we love gaming and want to make fun experiences accessible to everyone. Our games are available directly on our official website, with no downloads or accounts required.
